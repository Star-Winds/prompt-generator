# AI Prompt 生成器（AI Prompt Generator）V_0.3

一个用于 **快速生成结构化高质量 Prompt** 的网页工具（适配手机）。
通过填写任务描述、选择风格、长度、目标读者等信息，将模糊需求自动转为可复用的 Prompt，并在输入模糊时给出澄清建议。

## 📌 项目简介（Overview）

在学习与使用大模型的过程中，许多人无法写出明确、结构化的 Prompt，导致模型无法给出高质量回答。  
本项目提供一个简单、美观、移动端友好的 **Prompt 生成工具**，用户通过表单填写需求即可获得结构化 Prompt 并一键复制使用。

---

## ✨ 功能特性（Features）

- 输入任务描述，自动生成结构化 Prompt，默认补充基础质量约束
- 支持选择输出风格（严谨 / 口语 / 创意）
- 支持控制输出长度（简短 / 适中 / 详细），并根据长度给出格式提示
- 支持设置目标读者、约束条件等参数
- 提供常用场景模板（学习计划 / 文案 / 测试用例 / 头脑风暴 / 需求梳理）一键填充
- 根据任务关键词给出动态格式建议，避免输出千篇一律
- 输入过于模糊时自动生成澄清与补全提示，帮助你完善需求
- 一键复制生成结果，可直接下载为 .txt
- 新增「本地 Prompt 仓库」，自动保留最近 5 条生成结果，支持一键填充/复制
- 支持手动保存当前结果、清空仓库、重置表单输入
- 支持深色模式切换，夜间阅读更舒适
- 纯前端实现，无需服务器
- 自适应移动端界面（手机体验优秀）
- 部署在 GitHub Pages，可随时访问
- 可在本地填入 OpenAI API Key，直接用模型优化生成的 Prompt

## 🚀 使用方法（How to Use）

1. （可选）通过“快速场景模板”下拉框，一键填充常见场景示例，然后按需修改。
2. 在输入框中写下你想让 AI 完成的任务，可补充目标读者、必备约束等信息。
3. 选择输出风格、长度偏好等选项；若没有填写约束，工具会自动加入一组通用质量要求。
4. 点击 **“生成 Prompt”** 按钮，页面会同步提示需要补充的澄清点，方便完善后再次生成。
5. （可选）若要直接用模型生成/优化 Prompt，先在页面顶部的 **OpenAI API 设置** 中填写自己的 API Key（仅保存在本地），必要时填写自定义 Base URL 或模型，然后点击 “用 OpenAI 优化 Prompt”。
6. 点击 **“复制”** 将 Prompt 用于 ChatGPT 或其他大模型。
