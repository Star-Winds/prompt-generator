# AI Prompt 生成器（AI Prompt Generator）

一个用于 **快速生成结构化高质量 Prompt** 的网页工具（适配手机）。  
通过填写任务描述、选择风格、长度、目标读者等信息，将模糊需求自动转为可复用的 Prompt。

---

## 🌐 在线访问（Live Demo）

👉 https://star-winds.github.io/prompt-generator/

无需安装，打开即可使用。

---

## 📌 项目简介（Overview）

在学习与使用大模型的过程中，许多人无法写出明确、结构化的 Prompt，导致模型无法给出高质量回答。  
本项目提供一个简单、美观、移动端友好的 **Prompt 生成工具**，用户通过表单填写需求即可获得结构化 Prompt 并一键复制使用。

---

## ✨ 功能特性（Features）

- 输入任务描述，自动生成结构化 Prompt  
- 支持选择输出风格（严谨 / 口语 / 创意）  
- 支持控制输出长度（简短 / 适中 / 详细）  
- 支持设置目标读者、约束条件等参数  
- 一键复制生成结果  
- 纯前端实现，无需服务器  
- 自适应移动端界面（手机体验优秀）  
- 部署在 GitHub Pages，可随时访问

## 🚀 使用方法（How to Use）

1. 在输入框中写下你想让 AI 完成的任务  
2. 选择输出风格、长度、目标读者等选项  
3. 点击 **“生成 Prompt”** 按钮  
4. 点击 **“复制”** 将 Prompt 用于 ChatGPT 或其他大模型
